Kom i gang
Hva du får
Designsystemet er vanlige CSS- og JS-filer. Du trenger ikke npm eller en byggejobb. Du kopierer filene inn i prosjektet og lenker til dem.
Mappe eller filHva den har
frantz-ds.cssÉn fil som henter alt under. Lenk til denne.
tokens/base.cssFarger, tekststørrelser, avstand, radius og skygge. Henter også fonten Montserrat.
styles/reset.css, typography.css og layout.css. Ikke kopier docs.css. Den er bare for disse sidene.
components/Én mappe per komponent med CSS. JavaScript ligger i components/js/.
assets/Frantz-logo og kanallogoer.
Steg 1
Kopier filene
Kopier disse inn i prosjektet. Behold mappene som de er, for filene peker på hverandre.
Mapper og filer
frantz-ds.css
tokens/
styles/reset.css
styles/typography.css
styles/layout.css
components/
assets/
Steg 2
Legg til CSS
Legg denne linjen i <head> på hver side. Da har du alle tokens og alle komponenter.
I <head>
<link rel="stylesheet" href="frantz-ds.css">
Hvis filene ligger i en annen mappe
Endre stien, for eksempel href="/static/frantz/frantz-ds.css". Stiene inne i frantz-ds.css er relative, så de virker så lenge mappene står sammen.
Steg 3
Legg til JavaScript
De fleste komponentene trenger ikke JS. Legg bare til skriptet når du bruker komponenten i listen. Legg skriptene rett før </body>.
KomponentSkript
Portal-nav (meny på mobil), Datocomponents/js/interactions.js
Feltvelgerportal/data/frantz-data.js og så components/js/picker.js
Traktcomponents/js/funnel.js
Omvisningcomponents/js/tour.js
Sporingskodecomponents/js/piksel.js
Spør Frantz og Chatcomponents/js/assistant-widget.js og så components/js/assistant.js
Før </body>
<script src="components/js/interactions.js" defer></script>
Steg 4
Bruk en komponent
Gå til Komponentbiblioteket. Hver komponent har fem deler:
  1. Hva den er.
  2. Hvordan den ser ut.
  3. Hvilke filer den trenger.
  4. Teknisk: når du bruker den, klasser og regler.
  5. Kode: HTML du kopierer med «Kopier».
Lim inn HTML-en og bytt teksten. Ikke endre klassenavnene.
Eksempel: knapp
<button class="btn btn--primary" type="button">Ny kampanje</button>

Bare noen komponenter
Vil du ha mindre CSS, lenker du til filene én og én i stedet for frantz-ds.css. Ta alltid med de to første. Hver komponent i biblioteket viser hvilke filer den trenger.
Knapp og skjemafelt
<link rel="stylesheet" href="tokens/base.css">
<link rel="stylesheet" href="styles/reset.css">
<link rel="stylesheet" href="styles/typography.css">
<link rel="stylesheet" href="components/button/componentButton.css">
<link rel="stylesheet" href="components/form/componentForm.css">

Ikoner
Ikonene er Lucide (MIT-lisens). De er med i frantz-ds.css. Ikonet får samme farge som teksten rundt. Se alle i Stilguiden.
Ikon
<span class="icon-lucide icon-lucide--house" aria-hidden="true"></span>
Ikon ved siden av tekst får aria-hidden="true". En knapp med bare ikon får aria-label.
Mer
Egen CSS med tokens
Når du skriver egen CSS, bruk tokens og ikke faste verdier. Bruk de semantiske navnene, som --text-heading, og ikke rå farger, som --color-navy. Da følger siden med når designsystemet endres.
Riktig og feil
/* Riktig */
.min-boks {
  padding: var(--space-16);
  border: 1px solid var(--border-default);
  border-radius: var(--radius-12);
  color: var(--text-body);
}

/* Feil: faste verdier */
.min-boks { padding: 16px; color: #0C3F59; }
Alle tokens står i Stilguiden og i tokens/base.css.

Regler du må følge
  • Navy er standard for handlinger. Amber er for én nøkkelhandling per skjerm.
  • Aldri hvit tekst på amber.
  • Knapper er full pill. Felt har 8 px radius, paneler 12 px og kort 16 px.
  • Overskrifter er Montserrat 700.
  • Feilfarge er #B3261E. Sideflaten er hvit.
  • Ikke fjern fokusringen.
